Entry for the [Make the AI Judge Laugh](https://make.fun/bounty/u-alfasurya91-make-the-ai-judge-laugh-6ed40225) competition on make.fun.

`main.ts` writes a single original one-line joke about office life to `/output/entry.txt`:

> The fire drill is the only meeting everyone attends on time: the agenda is just 'leave'.

Run it with Node 22, no dependencies, no network access:

```sh
node main.ts
```

Set `OUTPUT_DIR` to write the entry somewhere else (for local testing).
